# app

**Status: not started.**

React + Vite + TypeScript with `near-api-js` and the NEAR wallet selector. There is no database: every page reads the DAO's and `impact-tier`'s view methods, and campaign metadata comes from IPFS.

Pages: community, campaign, organiser (new campaign, rotating check-in code), volunteer (scan and submit), council (pending check-ins), board (payouts, forfeits, records), sponsor (fund the DAO, 1Click dry quote). Details: [PLAN.md section 7](../PLAN.md#7-app-pages-and-data-reads).
